> "Your McKinsey DD team. Minutes, not weeks."

## Problem

A pre-seed VC analyst gets 20 startup decks a week. Verifying whether the team is real, the customer logos check out, and the growth story is consistent takes **4 hours per company** — done manually — before a partner even looks at it.

Current workflow: open 15 tabs, Google founders, check LinkedIn, search for news, look up G2 reviews, check if the privacy policy exists. Repeat for every company. Every week.

AuditAI does that in 3 minutes.

---

## Primary User

**Pre-seed VC analyst** at an early-stage fund.

- Receives 20+ startup decks per week
- Spends 4 hrs per company on basic background verification
- Pain is repetitive, data-gathering grunt work — not strategic judgment
- Would immediately recognise the value of automated cross-verification

Secondary users (roadmap only, don't mention in pitch): M&A associates, pre-IPO compliance teams, startups checking own readiness.

---

## Solution

AuditAI scrapes, cross-verifies, scores, and outputs a structured audit report on any company using **100% Anakin APIs** for data and Claude for interpretation and synthesis.

Input: company URL.
Output: risk scores across 6 categories + discrepancies found + analytical frameworks + exportable PPTX report.

---

## The 6 Audit Categories

| # | Category | What we check |
|---|----------|---------------|
| 1 | Legitimacy | Team page, founder names, company registration signals |
| 2 | Financial signals | Funding claims vs. news coverage, revenue signals |
| 3 | Online presence | SEO, press coverage, media mentions |
| 4 | Compliance | Privacy policy, T&Cs, legal pages exist and are substantive |
| 5 | Social proof | Customer logos cross-checked against case studies, G2, reviews |
| 6 | Growth signals | Hiring trends (careers page), product launches, momentum |

Each category gets a score 0–10. Claude generates a 2-sentence justification per score. Combined into an overall risk rating: green / amber / red.

---

## Analytical Frameworks (Claude-synthesized from Anakin data)

All five frameworks are generated by Claude using the scraped Anakin data plus pre-filled structural templates. No separate API calls per framework.

- **PESTLE** — macro-level external risks for IPO or acquisition context
- **SWOT** — quick company health check
- **Porter's 5 Forces** — competitive positioning analysis
- **Risk Heatmap** — scores across compliance, financial, operational, market
- **Benchmark KPIs** — compare against sector peers for hiring, growth, social proof

## Anakin API → Category Mapping

| Category | Anakin APIs used |
|----------|-----------------|
| Legitimacy | URL Scraper (About/Team page) + Search API (founder names) |
| Financial signals | Agentic Search (funding news) + Search API (revenue signals) |
| Online presence | Search API (press mentions) + URL Scraper (media/press page) |
| Compliance | Crawl API (privacy policy, T&Cs, legal pages) |
| Social proof | URL Scraper (customer logos page) + Search API (G2, reviews) |
| Growth signals | URL Scraper (careers page) + Agentic Search (product launches) |

**Claude's role is interpretation only** — it never fetches data. It receives structured markdown from Anakin and outputs JSON scores, framework content, and discrepancy flags.

## Tech Stack

**Backend — FastAPI (Python)**
- Single `POST /audit` endpoint
- Orchestrates all Anakin API calls in sequence
- Calls Claude for scoring and framework generation
- Returns structured JSON only — no file generation on backend

**Frontend — React + Tailwind**
- URL input field + "Run Audit" button
- Live loading stepper showing each Anakin call as it fires
- 6 score cards with bar + number + justification
- Tabs: Overview / Frameworks / Discrepancies
- Export button → PptxGenJS generates .pptx client-side + browser print-to-PDF fallback

**Why PptxGenJS over python-pptx**
PptxGenJS runs entirely in the browser. It takes the audit JSON that FastAPI already returns and generates the `.pptx` client-side with a direct download trigger. No extra backend endpoint, no file handling, no temp storage, no download route. Saves 30–45 minutes vs. a python-pptx implementation.

## Anticipated Q&A

**"You're just scraping public data — what's the moat?"**
Speed and cross-verification. We hit 8 sources simultaneously and flag contradictions between what a company says and what's actually findable. No analyst does that at this speed or scale. At 20 companies a week the time savings alone justify the tool.

**"Can you verify financials or legal filings?"**
We verify what's publicly stated versus what's live on the web right now. Not private filings — but the claims in a deck that any analyst would Google anyway. That's the grunt work we're replacing.

**"Who are the other users beyond VC analysts?"**
M&A teams, pre-IPO compliance, and startups checking their own readiness are all on the roadmap. We picked the VC analyst workflow first because it's the most frequent, time-pressured use case with the clearest ROI.

**"What if the company has minimal online presence?"**
Low online presence is itself a signal — it shows up as a low score in Online Presence and Legitimacy. A company claiming 500 customers with no press coverage is a red flag, not a gap in our tool.
